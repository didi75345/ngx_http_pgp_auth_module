ngx_http_pgp_auth

APT repository — PGP-signature authentication for nginx.

Install

# trust the archive key
curl -fsSL https://didi75345.github.io/ngx_http_pgp_auth_module/pgp-auth-archive-keyring.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/pgp-auth-archive-keyring.gpg

# add the repository
echo "deb [signed-by=/usr/share/keyrings/pgp-auth-archive-keyring.gpg] \
https://didi75345.github.io/ngx_http_pgp_auth_module $(lsb_release -cs) main" \
  | sudo tee /etc/apt/sources.list.d/pgp-auth.list

# install
sudo apt update && sudo apt install libnginx-mod-http-pgp-auth
sudo systemctl reload nginx

What you get

Module/usr/lib/nginx/modules/ngx_http_pgp_auth_module.so
Enabled via/etc/nginx/modules-enabled/50-mod-http-pgp-auth.conf
ReleasesDebian Bookworm, Debian Trixie
Dependsnginx-abi-<version>, gnupg

Each package is built against its own Debian release's nginx and depends on that nginx's ABI, so apt will refuse to install a module that does not match the installed nginx rather than leaving you with a server that will not start.

Configure

location /admin/ {
    pgp_auth              on;
    pgp_keyring           /etc/nginx/pubkeys.gpg;
    pgp_session_secret    /etc/nginx/pgp_secret.key;
    pgp_challenge_timeout 120s;
    proxy_pass            http://127.0.0.1:8080;
}
